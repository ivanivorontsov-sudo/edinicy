# Интерактивный конвертер единиц измерения и валют

Сайт: https://ivanivorontsov-sudo.github.io/edinicy/

Возможности:
- Поля ввода значения и выбора единиц для длины, массы, объёма, площади, скорости, давления, температуры и объёма данных.
- Автоматический пересчёт при изменении значения или единиц.
- Конвертер валют с загрузкой обновляемых справочных курсов через открытый endpoint ExchangeRate-API `https://open.er-api.com/v6/latest/{BASE}` без API-ключа.
- Отображение даты обновления курса и предупреждения о возможном отличии от курса банка или обменника.
- Адаптивная мобильная версия; расчёты выполняются в браузере.

Для таблицы браузер передаёт поставщику только код базовой валюты; введённая сумма и выбранная целевая валюта остаются локально. Провайдер получает стандартные технические сведения сетевого запроса. Курсы валют обновляются поставщиком примерно раз в сутки; они предназначены для справочных расчётов и не являются гарантированным курсом сделки.
